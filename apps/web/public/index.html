    Manual publish checklist

    Upload the same MP4 to YouTube Shorts, Instagram Reels, and Facebook Reels. VO-only — don’t attach trending audio ripoffs.

    YouTube Shorts

    1. Optional semi-auto: Upload to YouTube when OAuth is configured (private by default)
    2. Or YouTube Studio → Create → Upload videos
    3. Pick the vertical MP4 (≤60s)
    4. Title = script title; paste caption + hashtags
    5. Add stock credits from attribution if listed
    6. Disclose AI if required → Publish

    Instagram Reels

    1. Instagram app → Create → Reel
    2. Upload MP4 from camera roll / Files
    3. Cover: mid-frame with readable on-screen text
    4. Paste caption + hashtags
    5. Share to Reels (and Feed if you want)

    Facebook Reels

    1. Facebook app or Page → Create Reel
    2. Upload the same MP4
    3. Paste caption + hashtags
    4. Post as your Page if that’s the brand surface
