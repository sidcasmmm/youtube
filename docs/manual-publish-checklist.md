# Manual publish checklist (MVP)

After `npm run generate` finishes, use `output/short-*/short.mp4`.

## YouTube Shorts

1. Open YouTube Studio → Create → Upload videos.
2. Select the MP4 (must be ≤60s and vertical for Shorts treatment).
3. Title: use `script.json` `title` (keep under ~100 chars).
4. Description: paste CTA + hashtags from `script.json`.
5. Visibility: Public / Unlisted as needed → Publish.

## Instagram Reels

1. Instagram app → Create → Reel.
2. Upload `short.mp4` from camera roll / Files.
3. Cover: pick a mid-frame with readable on-screen text.
4. Caption: title + CTA + hashtags.
5. Share to Feed / Reels.

## Facebook Reels

1. Facebook app or Page → Create Reel.
2. Upload the same MP4.
3. Caption + hashtags; post as Page if that is your brand surface.

## Notes

- Do not rip trending audio; this MVP is **VO-only**.
- Disclose AI-generated content where the platform requires it.
- Official APIs (YouTube Data API, Meta Graph Reels) are post-M3 optional.
